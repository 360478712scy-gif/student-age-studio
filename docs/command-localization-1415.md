## 删除行为

`studioSocial.disabledConditions` / `disabledEffects` 只记录用户删除过的自动生成指令类型，不影响手动添加。切换离开社交类型时仍保留记录；变更类型和重开不再丢失。对话中的自动效果先核对用户是否删除，再执行位置同步；不因位置同步误判删除。未完成草稿的现有保存机制不变。
