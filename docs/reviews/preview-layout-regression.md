# 全屏预览人物错位与原版按钮回归

2026-09-20，Codex。基线：已发布的 1.3.11.4 / a84c4ef；本轮为本地修复，尚未发布。

## 原因与修复

- 真实开场对话 320201001（妈妈、主角）可复现：入场位置动画使用 `fill: both`，结束后仍覆盖节点的位置。静态立绘原生尺寸、模型边界较晚返回时，图片尺寸更新，而位置仍停留在旧的缩略图或占位尺寸对应的坐标，因此放大并错位。改为仅在动画开始前填充；结束位置由已重建的场景布局负责，加载和窗口缩放不再受旧终点控制。没有恢复隐藏编辑器重绘，也没有改写 Mod 人物参数。
- 右下角按钮没有被编辑器主题排除，背景和文字被主题覆盖。加入原版 UI 隔离；按 HotkeyView 原始布局恢复 0.7 倍整体缩放、26 字号、10 间距及文本宽度加 65 的按钮宽度。原版贴图、快捷键行为保留。
- 编辑器工具菜单是顶层 popover，单独调整 z-index 无效。全屏期间隐藏工具菜单和编辑器缓存指示器；退出后保留原来的展开/折叠状态。
- 原版对话框、日志框、快捷键分别在自身图片就绪后启用，不再被字体或另一组缺失图片阻挡。缺失的那组保留自己的备用样式。
- 真实原版覆盖样本另发现退出预览时，编号冲突提示直接读取未加载的原版正文；改为读取已有摘要，避免退出报错及额外全文读取。

## 验收证据

- 隔离复制缓存和原版对话，不修改用户 Mod、存档或原始游戏文件。Chrome 使用真实背景、妈妈静态立绘及主角模型截图，故意将尺寸/模型描述接口延迟 4.5 秒：动画结束后画面位置与新尺寸一致。
- 1920×1080、1280×800、2048×1180 三种尺寸，经典主题及三种配色 × 两种材质，悬停、日志、连续播放、退出恢复均通过；未改写对话和脏状态，菜单状态恢复。
- 四次连续切句约 13–15 ms，隐藏编辑面板 DOM 变动为 0；没有取消前一版本的预览性能修复。
- 同一隔离 CrossOver 游戏进程打开 320201001：记录原版妈妈 Sprite 原生尺寸 1081×2704、缩放 .63 与角色组件边界；与编辑器实际布局相符。HotkeyView 布局及原版 OnRenderKey 宽度计算已核对。游戏截图有新游戏欢迎提示遮挡，不作为完整画面视觉验收；CrossOver 不等同原生 Windows。
- 新增可重复回归 `standalone/tests/scene-preview-layout.cjs`：旧代码稳定失败（终点残留误差约 69 px），修复通过；`preview-ui-loading.cjs` 验证字体延迟、日志贴图失败不影响其他原版 UI。既有 actor-geometry、scene-entry、remote-scene 回归通过。
- 私有证据：工作树 `output/preview-regression/acceptance.json`、`accepted-1920.png`、`before-native.png`、`hotkey-geometry.json`；游戏原生数据见私有工程 `output/model-reference/game/probe.jsonl`。

1.3.11.4 的性能验收只用了无真实人物素材的大模组，未覆盖本次延迟几何回归；本次补充真实素材及故意延迟检查，不能沿用之前的性能结果宣称人物视觉已验收。尚未在反馈者的 Windows 客户端验证。
