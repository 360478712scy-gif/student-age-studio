# 人物图片参照与加载稳定性验收

日期：2026-09-19。实现与验收：Codex。基线：1.3.11.2；本次未发布新版本。

## 修复内容

- 小雅在游戏中使用 Live2D，人物页原先拿静态原图作参照，两者实际可见尺寸不同。现在使用与剧情预览相同的原版模型静态截图及原始边界、缩放参数；本页不创建实时模型渲染器。
- **2026-09-21 更正**：本报告原先将导入 Sprite 的 PPU 用于剧情静态图，结论错误。ResInfo.GetSpriteAsync 实际加载 Texture2D 并创建默认 PPU 100 的 Sprite；中学小雅静态图应为纹理高度 2048。1.3.13 已改为 Texture 尺寸并升级缓存 v5；图集独有 Sprite 才使用其 PPU。模型截图边界算法不变。详见 portrait-texture-runtime.md。
- 两侧图片及尺寸都完成加载后再展示、开放拖动与滚轮，防止先按单侧尺寸放大，另一侧到达后再缩小。切学段、类型或人物后，旧异步结果不能覆盖当前画面。
- 半身照、Q 版人物共用原生尺寸单位；头像、Q 版头像、照片表情按钮和企鹅头像按相同显示框对照。不同游戏页面本身仍有各自的显示框。
- 修改参数沿用原字段：静态图写 urlParm，原版模型写 l2dParm；打开页面不自动改写人物资料。

## 实际游戏证据

隔离 Windows Unity 游戏通过 macOS CrossOver 运行，原游戏、真实 Mod、存档未修改。利用隔离测试驱动读取原版 UI 的 Sprite、尺寸、缩放和模型边界；以下后半段类型在同一个游戏进程连续切换完成。

| 类型 | 核对方式与结果 |
| --- | --- |
| 剧情立绘与气泡 | 原版人物图片编辑器：导入按编辑器参照匹配的 PNG，与原版小雅模型并排显示，人物与气泡尺寸对应；小学/中学另做编辑器检查。 |
| 半身照 | 原版 UISprite 的 NativeSize 路径：左右均 646×1000、缩放 1、PPU 100。游戏交涉页面也使用此尺寸策略。 |
| 人物头像 | 原版 UISprite 固定显示框：左右相同；编辑器额外检查高分辨率导入不会扩大显示框。 |
| Q 版人物 | 左右原生尺寸均 114×137；图集纹理为 1024×512，没有拿整张图集当人物尺寸。 |
| Q 版头像 | 改用有该资源的薛诗蕾，固定框左右一致。小雅没有独立 Q 版头像资源，界面显示读取失败并允许换参考，不伪造图片。 |
| 照片表情按钮 | 独立导入图与原版图集中的 428×450 Sprite 在同一固定框显示一致。 |
| 合影 | 复用人物立绘/模型参数，编辑器真实素材检查通过；未走完整约会拍照流程。 |
| 企鹅头像 | 编辑器实际素材与同框检查通过；未另走完整空间浏览流程。 |

半身照、头像、Q 版、照片按钮的游戏检查是实际 Unity UI 组件对照，并非每种图片都自然游玩到其业务页面。主角特殊服装及任意自定义 Live2D 模型未逐一验收，不将这一组样本称为所有素材绝对无误。

本地证据（不公开分发游戏素材）：私有工程 output/model-reference/game/native-matched-clear.png；native-*-metrics.json；工作树 output/model-reference/editor-final.png、browser.json。部分组件截图有新游戏提示遮挡，尺寸结论同时由原生组件属性记录支持。
