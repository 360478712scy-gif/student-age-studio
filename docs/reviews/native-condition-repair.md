# 普通条件恢复原版协议

2026-10-05；1.4.13 的普通条件修复。

## 原因与范围

条件目录把属性和好感比较写成 `[4/7,9001..9006,id,value]`。这 12 类编号由旧 Studio 运行扩展定义，原版 `ConditionerAttr` / `ConditionerRelation` 不识别；普通编辑模式也生成它们，导致没有该扩展的游戏不能满足条件。

已核对原版 `native-all.cs`：`ConditionerAttr` 的 subtype 1 为带 0.001f 容差的 ≥、2 为 <、3 为 ≥ 下限且 < 上限；`ConditionerRelation` 的 subtype 1 为 ≥、-1 为 <。好感值和阈值使用 float，不能把严格大于一律改成“加 1”。条件列表以 AND 连接。

- 新建属性只提供 ≥、<、范围；好感只提供 ≥、<。上下界相同的属性范围不代表等于。
- 删除 12 类 Studio 数值模板，并过滤旧目录缓存及观察样本；预览不再解释这些旧编号。
- UP、其他插件和未知命令，以及原版固定判断、命名前提、效果指令均保留。检查未发现其他需要删除的 Studio 数字 opcode。旧插件的服装、分支、音频等编辑元数据不按名称删除。

## 旧数据修复与保存

在打开工坊、剧情或新分段项目之前检查本地可写 Cfg。只修改真实条件字段中的旧 Studio 命令；EvtCfg 还同步已知的 studioSocial.conditions / entryConditions 归属镜像。不改台词字符串、效果、未知字段、其他命令或编号。事务沿用跨进程保存锁、修订检查、备份、原子替换和回滚；不会写原版资源或只读订阅模组。

可证明等价的比较转换为原版条件。好感等于在 AND 列表中拆为 ≥ 与 < 的精确 float32 边界；属性转换考虑原版的容差。无法等价表达的“不等于”、部分属性边界及不能容纳 AND 的单条件字段，按用户选择保留并提示手动修改，不放宽或删除限制，也不阻止保存。个人条件配置会备份后迁移，其他模组的可复用组合在读取时转换而不写入其文件。

每个文件按指纹和条件字段缓存结果，包括无法转换的提示。扫描在 Store 锁外进行；提交前再次校验。普通送礼、其他表和剧情保存不进入磁盘迁移扫描；只检查这次实际提交的记录和对话增量，挡住旧浏览器草稿重新写入可转换的指令。已验证仅正文变化的保存会前移条件缓存指纹，避免随后打开项目重新解析全部对话。

## 验证入口与边界

- `standalone/tests/test_native_condition_migration.py`：有限 float32 相邻值与随机值、负数、小数、极值、无法表达条件保留；磁盘命令 token、BOM、UTF-8、UP 和未知内容保留；事务、指纹冲突及缓存。
- `standalone/tests/test_native_condition_repair.py`：只修改目标命令 token，明确的社交条件镜像、其他表同名未知字段、科学记数、缓存、备份和文件冲突。
- `standalone/tests/test_native_condition_integration.py`：真实 HTTP 打开 → 修复 → 建立分段底稿 → 送礼保存、正文保存缓存前移、旧草稿增量防回写、个人配置备份及旧目录过滤。
- `standalone/tests/condition-native-numeric.cjs`：生产条件目录的新增、切换、应用、范围边界、遗留提示、插件保留及用户配置提示。
- `output/native-conditions/benchmark-500k.json`：隔离 50 万句 / 91.78 MB，首次修复含备份 4.57 秒，缓存再次检查 6.38 毫秒，磁盘缓存恢复后 4.32 毫秒。两条缓存路径均禁止扫描仍通过。此为 macOS / Python 3.14 测量，不能当作 Windows 编辑器实测；基准进程额外持有三份大 fixture 字节。
- `standalone/tests/condition-native-full-ui.cjs` 与 `output/native-conditions-full-ui/full-ui-result.json`：实际生产应用与后端的工坊 → 剧情 → 事件设置 → 条件目录 → 正式顶部按钮保存 → 整页刷新重开。原版符号、数值、未转换提示、UP 和未知字段均保留。测试使用临时 Mod 与应用随带的 schema 暖缓存，不启动原版解包。

35 项后端转换、读写及既有保存性能回归通过；两条生产浏览器流程通过。证据不公开用户 Mod 或本地会话令牌。

检查使用隔离 Mod。源码和浏览器验证不等于原生桌面发行包或 Unity 游戏实机验收；本轮没有取得反馈者完整 Mod。发布与升级验证另记。
