# 人物切图与全部剧情导出

作者：Codex；2026-09-20；发布版本 1.3.11.9。

## 改动及依据

- 可复现路径：切换学段后保留旧位图，却立即使用新学段 urlParm。隔离复现的旧图高度从 328.125 变为 984.375。现在将位图与学段、主角性别绑定，替换就绪前沿用旧图对应参数；同 URL 复用也经过就绪检查。未改作者的缩放、动作或 Mod 数据。
- Windows 完整窗口首次查尺寸会解包约 442 MB 的原版 role 包。内置 1625 条既有 Sprite 原生尺寸，只有文件长度及 SHA-256 完全吻合才复用；不同版本仍走实际读取，磁盘缓存仍按文件指纹失效。只分发数值元数据，不含游戏图片。
- 事件页排序按钮后增加“导出全部剧情”。复用单事件 TXT 格式，按当前排序导出所有事件；正文按 100 条读取并复制，包含未保存修改。共用节点在所属事件分别列出，循环不无限展开；选项、条件分支、无对话通知和空事件保留。外部未载入对话明确标注 ID。导出不切换事件、不保存 Mod，读失败不写残缺 TXT；上限 64 MB。

## 验收范围

- Windows 11 原生 WebView2 完整编辑器、真实原版人物参数与背景：4 次实际鼠标拖放、3 次舞台切句、2 次预览翻句及退出通过。妈妈/爸爸的游戏单位高度约 1703.52/1825.74，在舞台与全屏预览间一致。不是游戏内运行验收。
- Windows 筛选列表只显示 1 个事件，实际导出完整 45 个事件，未保存正文、当前事件/选句/脏状态均保留。
- 独立渲染器测试覆盖延迟切图、同图片性别参数、反复刷新及拖动；临时测试页使用人为缩放，仅作为数值回归，不作为正式 UI 展示或比例验收。
- Node 6 套定向回归通过；Python 大 TXT/尺寸元数据/保存与图片请求竞争 6 项通过。发布 CI 再执行已有三平台回归。
- 证据：私有工作树 output/portrait-export/windows-full-results.json、windows-full-stage.png、windows-full-preview.png、windows-results.json；公开可重复用例 standalone/tests/scene-retained-geometry.cjs、all-story-export.cjs、test_story_export.py、test_picture_dimensions.py。
- 反馈者原 Mod 未取得，截图的具体触发链尚不能唯一归因。
