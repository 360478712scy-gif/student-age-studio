# 未完成配置保存与分支修复（2026-10-08）

## 根因与改动

- 条件目录计数先增加，随后为了展示对话引用直接访问尚未载入的正文，render 抛错。改用对话目录摘要、延迟分页与当前已编辑正文；条件窗口打开期间暂缓自动编号，关闭后再改编号和引用。
- 分支文件夹只是编辑器归属记录；外部编辑器删改实际对话后，旧记录仍被当作有效归属，sync 又在半途报缺连接。前后端以实际图释放失效归属，保留正文和实际连接；普通正文保存快路同样提交待清理记录。
- 放弃修改把整张 order 数组传给增量 undo 恢复器，引发 slice 错误；改为整数组恢复，并恢复已保存固定编号。
- 多个页面、事件设置和后端 save_review 各自把完整度当作保存门槛。普通配置校验现在是成功保存后的 warning；事件绑定、音频、用途等未完成草稿持久保存，安全派生失败时保留旧的游戏配置，补齐后可恢复派生。物品/书籍/效果的原文草稿也能继续编辑。
- 成功保存需要清除已确认的输入脏标记，避免仍被 dirty/flush 视作永远未保存；真实写入失败保留草稿并报告失败。
- 新事件绑定草稿的引用纳入编号改写；未知字段、插件命令和不相关数字保留。
