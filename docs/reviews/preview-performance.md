# 大模组预览、退出对话与条件目录性能复核

2026-09-20，Codex。本批修复纳入 1.3.11.4（协议 1.3.12-beta.4），用户已授权发布；基线为 1.3.11.3 / 3b6d1c6。

## 需求与已修复开销

用户明确是“编辑事件里的对话，退出回事件列表之后长时间正在处理”，不是事件设置的应用按钮；另有预览、打开 Mod、读取条件目录慢。

- 全屏剧情切句不再刷新隐藏编辑列表、人物选择和配置面板，退出仍恢复编辑视图。
- 事件计数按分段图版本和选项缓存：正文修改复用，连线/选项/入口/删除及撤销后重新计算。列表不再计算未使用的未归属对话；空搜索不计算所有事件条件摘要。可见卡片首句批量读取。
- 暖 /api/project 原先先完整 load 做旧音乐迁移，绕过分段缓存。无托管 BGM 跳过迁移；有 BGM 按真实修订缓存已完成检查，外部修改重新校验，原修复写回行为保留。
- 条件/效果引用改为批量只读接口；前后真实修订一致性检查、分表失败提示，不缓存失败。已加载人物/事件/选项/对话叠加当前草稿并保留原版引用。正常完整表 API 不变。最多 4 组缓存，每组 JSON 字符预算 4 MiB。
- 条件库 get/get_mods 由任意文件变动后全读，改为按文件指纹和 schema 复用提取结果，最多 256 张表；只重读改变的文件。对话引用标签使用摘要，避免强行读取正文。

## 验证

真实本地服务 + Chrome，20,000 句、10 事件、3,000 选项、600 人物/背景/CG；另加 1,000 对话夹。基线来自已发布 main，全部隔离数据。

- 25 次预览切句中位：146→10 ms；隐藏面板变更 700→0。历史 1–26 一致，退出前后选择/草稿一致。
- 改台词后四次返回列表：基线 71–104 ms；修复验收 18–77 ms，后两次 18/45 ms。没有 /api/project 或保存请求，文本保留。首句分页请求由 14 次降到 2 次（可见范围回调）。
- 顶部历史后退含自动保存 582 ms，仅 /api/save 和 /api/project-revision，无模组重开，返回事件列表且保存完成；随后回主页 62 ms。未更改自动保存语义。
- 后端 230 项：225 通过、5 既有跳过。新增真实暖打开不 mock repair、音乐迁移缓存/外部修改/修复写回、原版引用保留、分表失败重试、同尺寸恢复 mtime 的外部变更、409 冲突、条件索引仅重读改变 JSON 验证通过。
- remote-talks、remote-scene 分支路径等价、登场归属 15 项、关系事件可选行动、事件计数缓存失效/批量首句及未加载正文标签验证通过。

## 尚未证实

Windows 上数分钟阻塞未在本机复现，不能声称反馈全部解决。本轮没有原生 Windows/真实素材长期验收。合成 Game 目录无原版 UI 素材，/api/preview-ui 返回 500 并保留备用界面；这些请求约数毫秒，不作慢请求归因，浏览器无未捕获错误。未改保存原子备份与完整文件字节替换边界；首次索引仍有成本。
