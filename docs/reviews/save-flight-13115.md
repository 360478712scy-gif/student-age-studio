# 1.3.11.5 预览、保存与目录验收

作者：Codex；2026-09-20。沿用若心知 PR #4 已采纳部分，本次不改变其贡献归属。

## 原因与改动

- 图片解码与原生几何异步到达，先显示占位几何会出现突然放大/位移；延迟安装首张图片，换装期间保留旧图，尺寸就绪后安装。与此前 eca998e 的动画终点修复一同发布。
- 首次进入预览取消合成转场；保留后续换场、作者设置的屏幕效果。
- `/api/portrait-dimensions`、`/api/talk-head` 不再在解包/生成图片期间持有编辑器位置锁、保存锁。独立 HTTP 回归让图片读取保持阻塞，验证保存仍先完成。
- 保存空对话夹不遍历原版 ID；无删除重定向不生成原版 ID 集合；新增 ID 冲突检查仅访问相关配置表，实时文件指纹、备份、原子提交不变。
- 条件/效果目录从模组主页预加载，共享正在进行和已完成的请求；项目、模式、修订变化时更新，失败可重试。自动恢复主页入口也覆盖。
- 已存在的小游戏行动目录不再重新解包；素材索引改变不重读未变化的核心配置目录。
- 普通对白可拖入选项/条件分支夹，同步入口和后续播放连接，并可撤销/重做。带独立分支、小游戏或多个出口的句子仍拒绝直接搬移，避免隐式重写整组分支。
- 临时编号与磁盘/服务端已占用编号分开，撤销/重做/删除释放未保存占号；改号保留安全边界。对话夹新句继承前句场景只读结构，不强制载入前句正文。

## 验证

- Python 235 项：230 通过、5 平台依赖跳过；保存竞争、实时外部文件修改、目录失效和缓存复用均有定向回归。
- Node 11 套逻辑回归，包括初始/后续转场、目录请求合并、草稿编号、拖放路由、远程对话正文按需读取。
- Windows 11 原生 WebView2 源码窗口，使用真实游戏安装与隔离 Mod、缓存：49 句含实际图片、表情和背景两次首存约 0.67 / 0.90 秒，其中 0.90 秒一轮后端约 0.78 秒，未出现一分钟卡死。此为单机隔离样本，非反馈者电脑，也不等同完整打包客户端或游戏内所有流程。
- 同一 Windows 窗口验证延迟模型边界、换装保留旧图、延迟静态尺寸的首个可见帧；没有以错误占位尺寸先显示。
- Windows 实际拖放、撤销重做、选项/条件分支临时 ID 复用、自动改号后唯一性、保存重开后夹内容与行 ID 保留通过；主页目录两次请求，进入编辑仍为两次，未重复获取。
- 原始证据：私有 `output/save-flight-fixes/`；更新器激活、启动健康标记、失败启动及手动回退证据：`output/release-13115/`。

用户机器的一分钟保存/长期卡顿尚未直接复现，不宣称所有卡顿已解决。
