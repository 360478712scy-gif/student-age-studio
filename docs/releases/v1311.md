# 拾光工坊 1.3.11

- 改善大模组保存、切换功能和素材选择的速度：正文按记录处理，其他配置按涉及的表保存，减少重复载入、扫描和改号读取；保留备份与外部修改冲突保护。
- 补充恋爱社交事件类型和可视化文字提示效果配置。
- 剧情事件按名称排序时识别数字顺序；社交分类合并并排除关系事件，移除社交小游戏事件类型入口。
- 筛选栏保持单行，点击“自定义”在二级窗口选择保留哪些预设标签，或建立固定包含指定事件的命名标签。“全部事件”固定保留，电话标签默认隐藏。
- 送礼事件与事件外对话的送礼用途共用对话夹，保存时同步原生送礼入口。
- 修复自动生成的前提删除后又被补回的问题。
- 对话编辑区底部增加与原版一致的“动作指令”框，支持查看、修改和撤销当前句的动作指令。
- 更新失败时增加备用获取入口和重试处理。

本次为轻量代码更新。已完成隔离浏览器与定向回归，筛选界面经独立子 agent 审核；Windows 原生交互、真实模组长期压力和游戏送礼触发仍待进一步反馈。
