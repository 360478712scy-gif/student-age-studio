# 拾光工坊 1.3.6

事件外对话的左侧对话夹新增右键“用途…”。选择用途后在参数窗口配置，应用进入草稿，保存模组时把对话入口与参数一起写入游戏 CFG。

- 送礼：选择人物、具体礼物、主角性别、触发条件、交付方式和首次提示。无附加条件时按所选人物与礼物匹配；重复规则会报冲突，避免被另一条入口抢先匹配。
- 小游戏：选择人物、第 1～5 关和开场／胜利／失败。小游戏沿用人物页绑定；未绑定、关卡不存在或多个用途抢占同一入口时拒绝保存并给出说明。同一小游戏被多个人物共用时，关卡对话也共用。
- 其他入口：闲聊互动、使用物品、目标完成／失败、CG 回忆、恋爱画作、交涉六个阶段／性别入口、输入答案匹配／默认分支、对话与选项的继续／失败分支。已存在的原版配置引用可在用途窗口中识别、配置。
- 同一对话夹可绑定多个用途。保留其他人物、性别、阶段、答案及未知配置字段；支持草稿取消／撤销、编号同步，解除新增绑定时恢复原来的对话入口。
- 人物选择复用素材选择界面，目录显示 ID；四主题使用相同流程。修复右键菜单在部分画布区域点击外侧不关闭，以及编辑事件外对话正文时误改列表编号文字的问题。

原版预留的恋爱问候与人物活动 CFG 未找到已启用的播放入口，因此在用途列表中说明并禁用，不把“写入一个字段”当作可用触发功能。新用途不会替玩家完成目标、解锁画作、创建小游戏或满足额外触发条件。

用途参数与引用由原版反编译调用及 CFG 交叉核对。针对性保存／引用回归与四主题浏览器检查通过；真实游戏内全部用途、Windows 和 Mac 原生窗口完整交互仍需要进一步验收。

先发布轻量在线更新，再发布 Windows x64 与 Mac arm64 完整客户端；Releases 仅放两端完整客户端，不附加补丁包。保留 1.3.5 hotfix 的服装、表情差分、电话和空事件修复。

感谢若心知（ruoxingzhi，PR #1）的性能优化贡献；原贡献署名保留。本次用途功能、回归和修复由 Codex 完成。
