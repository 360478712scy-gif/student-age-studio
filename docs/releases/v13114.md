# 拾光工坊 1.3.11.4

- 优化大模组剧情预览：播放和切句时减少隐藏编辑界面的重复刷新。
- 优化编辑对话后返回事件列表：复用对话数量统计，并批量读取可见事件的首句；修改正文无需重新遍历对话关系。
- 优化条件和效果目录：复用已加载的内容，减少重复读取；条件库仅重新索引发生变化的配置文件。
- 优化重复打开模组时的旧音乐兼容检查，避免无须修复时仍完整读取对话。
- 保留草稿、撤销、自动保存、音乐兼容修复和外部修改冲突保护。

2 万句隔离样本中，剧情切句中位耗时由约 146 毫秒降至约 10 毫秒。用户反馈的 Windows 数分钟等待尚未在本机复现，仍需实际使用反馈，本次不宣称所有卡顿均已解决。

界面版本 1.3.11.4；更新协议使用旧客户端可识别的 1.3.12-beta.4。本次为轻量在线更新，已有客户端可直接检查更新。
