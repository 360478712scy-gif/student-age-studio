# 1.3.7.4

剧情、事件外对话和闲聊支持多选后批量删除。点击“多选”逐句勾选，Shift 选择连续多句，也可以全选本页；右键已选对话可以删除所选。

删除前显示句数供确认。整批只产生一次撤销记录，剧情连接跳过删除的句子，处理分支辅助记录、共享入口及音频引用；事件外对话夹和闲聊沿用原有保存与用途绑定链路。全删后保留空事件或闲聊框架。确认期间内容变化会取消删除，避免删除错行。四套主题共用同一操作。

隔离模组实际点击验证包含连续/非连续选择、取消、右键、撤销重做、共享事件入口、条件分支、整夹/整段删除、保存重开、无关记录保留。引用重连有 201 项对照检查，现有保存和用途检查继续通过。未进行 Windows 原生窗口及真实游戏验收。
