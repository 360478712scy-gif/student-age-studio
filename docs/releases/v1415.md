# 拾光工坊 1.4.15 · 指令说明与手动删除修复

- 补齐 64 项条件和效果的中文名称、参数与说明，包括人物所在地点、人物关系、表白成功率、跨周目记录、商店和活动相关指令。
- 人物所在地点支持显示已有的多个地点；缺少人物或地点资料时显示原编号，避免变成“未命名内容”。
- 手动删除事件类型自动添加的地点、好感和概率条件后，切换类型、保存和重新打开不会再补回；手动添加仍然有效。
- 对话里删除自动添加的亲密度效果后，不再被保存流程重新补回。
- 已有旧指令照常保留。已核对原版未实现的遗留指令会显示说明，不作为正常新建选项推荐；未知插件指令保留原值，不改写。

这是已有客户端的轻量更新，在工坊设置 → 版本与反馈中检查更新即可。新用户可先安装 [完整客户端](https://github.com/360478712scy-gif/student-age-studio/releases/tag/v1.4.10-beta.5)。
