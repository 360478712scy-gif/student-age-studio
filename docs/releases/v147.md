# 拾光工坊 1.4.7

**服装修复**
- 对话编辑右侧选择的服装一定生效：人物在这句还没明确设置服装时，下拉框显示「自动」。选择任何一套都会写入「更换服装」，之后的句子和换背景后都保持，游戏里也按它显示。此前如果选择的正好是预览已经显示的那套，编辑器不会写入指令，游戏里可能显示成别的服装。
- 剧情预览不再根据人物页的设置自动换装，只按剧情里写入的「更换服装」和原版规则显示，编辑器里看到的就是游戏里的样子。已有剧情里的服装不会被改动。
- 人物页去掉「设置穿着地点」（这项设置在游戏里从未生效），改为「修改服装名称」，并说明原版规则：在学校教学楼、学校操场与人物互动时穿「服装 2」，其他地点穿默认服装，所有人物相同。

本次为编辑器轻量更新，不改动模组文件格式。
