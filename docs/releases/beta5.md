# 拾光工坊 1.3.0-beta.5

这是现有客户端的轻量更新（约 2.4 MB），不用重新下载安装整个软件。

- 小型选择菜单点击外部关闭；工坊设置中可排除不参与 ID 重复提示的模组；缓存进度球仅在首次完整缓存时出现，之后后台静默补充。
- 编号直接在原位置输入，Enter 确认、Esc 取消，保留关联引用处理和撤销。
- 屏幕效果新增电话背景、本地人物、电话另一端人物及挂断设置。事件外对话和闲聊支持 emoji 与屏幕效果。
- 人物“图片与大小”页增加立绘、半身照、人物头像、Q 版人物和头像、大头贴合影／表情按钮、企鹅头像入口。只对游戏支持的图片提供尺寸参数；右侧显示原版人物参考。
- 事件外对话新增对话夹与逐句编辑；小游戏、电视节目、大头贴相框增加主页入口，电影入口保留。
- 效果选择新增“直接成为恋人”，选择人物即可。

## 现有用户如何更新

在“工坊设置 → 版本与反馈”检查并下载，完成后保存并重启。本次是旧客户端切换更新通道的一次兼容更新；从本版起，启动后会检查并后台下载 GitHub 的轻量更新，常规更新不再依赖新 Release 或完整客户端打包。重启前仍会保存所有草稿。

## Windows beta.4 启动失败

若提示 Python.Runtime.Loader.Initialize，下载本页 `StudentAgeStudio-Windows-launcher-beta4.zip`，关闭软件，将里面的“拾光工坊.exe”替换到已解压 beta.4 客户端的同名位置，保留 runtime 文件夹。

这是小启动器补丁：仅在确认运行库与官方 beta.4 完全一致后解除对应 DLL 的下载标记，不修改系统防护。也可先对原始客户端 ZIP 右键“属性 → 解除锁定”，再重新解压。启动器本身尚未使用商业代码签名，系统对新下载 EXE 的信誉提示仍可能出现。

## 首次安装

完整客户端继续使用 [beta.4 下载页](https://github.com/360478712scy-gif/student-age-studio/releases/tag/v1.3.0-beta.4) 的 Windows x64 或 Mac arm64 ZIP，再进行本次应用内更新。Mac 需要 Apple Silicon 和 macOS 14+。
