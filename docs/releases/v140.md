# 拾光工坊 1.4

本次重点修复大型模组的卡顿与卡死，改善 Windows 上的运行速度，并新增一套可选界面主题。

- 修复点击「新建事件」后卡死；大型模组（数万句对话）上现在约 1 秒即可打开事件设置。
- 大型模组打开剧情编辑从约 100 秒缩短到数秒；进入事件、添加对话等编辑操作明显加快，长时间编辑不再越来越卡。
- JSON 界面改为分段读取：只加载当前事件的对话（每段 200 条，可翻页），打开大型模组的 TalkCfg 不再需要等待数分钟；保存时只写入改动，不会整份重写文件。
- 物品标签选择器不再重复显示同名标签（人物送礼回应行不再混入标签列表）。
- 本地服务改为复用连接，打开模组时传输的数据减少约三分之二，Windows 上加载更快。
- 新增主题「纸本 · 工作室（新布局）」：暖纸底色、单行工具栏、右侧停靠工具栏、底部状态栏和更紧凑的对话列表。可在「工坊设置 → 界面主题」中选择；原有主题和默认外观保持不变。

本次为编辑器轻量更新，不改动模组文件格式。已通过自动回归测试，并在大型创意工坊模组上完成打开、新建事件、编辑、撤销和 JSON 分段保存的流程验证。
