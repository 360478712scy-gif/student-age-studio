# beta-1.3.4

本次资源读取、缓存与人物渲染优化来自 **若心知**（GitHub：[ruoxingzhi](https://github.com/ruoxingzhi)）的 [PR #1](https://github.com/360478712scy-gif/student-age-studio/pull/1)。**感谢若心知的贡献 🙏**

- 图片、音频读取与校验减少重复读取和额外内存占用。
- 为校验缓存设置上限，分批淘汰摘要缓存，避免一次全部清空。
- 人物贴图按需加载，分条计算渲染，减少大型图片的瞬时内存占用。
- 可重新生成的缓存索引减少强制磁盘同步，用户模组数据继续保留原有保存保护。
- 保留 beta-1.3.3 的空白对话入口修复，以及此前的电话、条件效果目录和素材选择改进。

Codex 在审查整合中修复了文件指纹缓存可能漏检外部修改、目录别名影响排除规则及图片资源释放的问题；保留原有 Windows 浏览器缓存位置和后台去重等待间隔，并补充保存、目录排除、索引恢复等回归检查。若心知的原始提交及贡献归属保留在合并历史中。

合成渲染样本的图片输出保持一致，峰值内存有所下降；这不代表所有素材、全部硬件或原生客户端的整体性能。验证范围以对应提交的自动检查结果为准，真实游戏和完整原生界面仍需持续验收。

本版沿用轻量更新通道，无需重新下载完整客户端；完整 Windows 与 Mac 安装包暂不重打。
