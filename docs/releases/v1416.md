# 拾光工坊 1.4.16 · 工坊关联修复

- 发布窗口新增“工坊条目关联 → 解除关联”。删除原工坊条目后，可以解除旧关联，再发布为新条目。
- 解除后不再从旧配置重新读回失效编号，后续更新会使用新发布的条目。
- 保留模组内容及原关联备份；解除操作本身不会上传或删除工坊条目。
- 上传提示条目不存在时，显示解除关联的处理说明。

这是已有客户端的轻量更新，可在工坊设置 → 版本与反馈中检查更新。新用户可先安装 [完整客户端](https://github.com/360478712scy-gif/student-age-studio/releases/tag/v1.4.10-beta.5)。

验证包含 32 项发布后端测试及浏览器解除、取消、重新发布流程。使用合成数据和模拟工坊接口，未上传实际模组或进行 Steam 实机发布验收。
