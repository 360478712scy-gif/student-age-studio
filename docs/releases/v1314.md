# 拾光工坊 1.3.14

- 修复永久卡死：保存、备份、用户条件配置与错误日志的文件锁不再无限等待，抢不到锁时给出中文提示并可重试；锁被占用时诊断日志也不会丢失。
- 修复打开模组、切换事件或预览时的长时间等待：立绘尺寸测量不再在请求里解包原版立绘资源，改由独立低优先级进程完成；测量失败按 30/60/120…300 秒退避，不再每次操作都重开一次进程。正常机器的尺寸仍会照常补上。
- 修复冷缓存下立绘尺寸被导出图粘住：原版立绘不再拿导出预览图的像素当尺寸，避免打开模组后整场会话里人物偏小或错位。
- 加载与响应优化：素材列表不再对每个素材文件重复读取指纹（再次打开同一列表时文件打开次数约降到十分之一）；原版资源与指纹读取不再长时间占用前台请求。
- 更新说明：本次是编辑器代码更新，不修改模组、存档与游戏文件。

验证：三平台 CI 检查通过；本机 macOS 使用真实游戏数据与隔离临时模组验证启动、打开模组、切换、保存与加载路径。本轮未进行 Windows 原生窗口与游戏内验收。
