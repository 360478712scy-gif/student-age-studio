# 拾光工坊 1.4.13 · 条件修复

- 修复普通模式生成原版不识别的属性／好感条件。好感只提供 ≥、<；属性提供 ≥、< 和范围，范围上限不包含在内。
- 打开本地可写模组时，自动将旧编辑器数值条件转换为等价的原版写法，并先备份。个人条件配置同步修复；UP、其他插件、未知指令和编号保留。
- 无法等价转换的条件保留并提示位置，方便手动修改，不删除剧情限制，也不阻止保存。
- 修复结果按文件缓存，普通保存只检查本次提交的记录，避免送礼或其他表保存重新扫描大量对话。旧浏览器草稿也不会重新写回可转换的错误条件。

可在工坊设置 → 版本与反馈中检查更新。本版为已有客户端的轻量更新。

更新入口空白的旧版本用户，可先使用 [1.4.11 的更新入口恢复工具](https://github.com/360478712scy-gif/student-age-studio/releases/tag/v1.4.11)。新用户可先安装 [1.4.9.5 完整客户端](https://github.com/360478712scy-gif/student-age-studio/releases/tag/v1.4.10-beta.5)。

转换、备份、保存与缓存回归，以及完整编辑器浏览器保存重开验证通过。隔离 50 万句模组首次修复含备份约 4.57 秒，缓存检查约 6 毫秒（macOS 测量）；本轮未作 Windows 原生或游戏内验收。
