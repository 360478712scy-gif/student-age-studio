# 拾光工坊 1.4.9.5

- Windows 启动失败时提供运行环境诊断与修复入口；正常启动不弹出检查窗口，也不重复安装系统组件。
- 完整 Windows 包附带微软 .NET Framework 4.8 离线安装器。仅确认启动失败源于 .NET 缺失或过旧时，手动运行 `prerequisites` 目录里的安装器；不自动安装或重启。
- 剧情编辑新增上一句、下一句快捷键（默认 Alt+↑ / Alt+↓），可在「工坊设置 → 外观与偏好」中修改、停用或恢复默认。
- 对话每页显示 100 句，事件每页显示 50 个；切换对话快捷键可以跨页定位。
- 保持后台分段读取，不设置单个事件的句数上限。

本版提供完整 Windows 64 位客户端（`with-NetFx.zip` 附带 .NET 离线安装器，原 ZIP 保留）。完整解压后打开最外层的「拾光工坊.exe」。启动诊断与修复属于完整客户端；已有客户端的轻量更新提供列表和快捷键功能。

内部标签为 `v1.4.10-beta.5`，编辑器界面显示 1.4.9.5，保持旧更新器的版本排序。
