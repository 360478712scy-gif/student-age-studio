# 拾光工坊 1.5.1 · 事件地点与非假期选项修复

- 事件选择“发生地点”时，不再额外生成“人物当前必须在该地点”的前提，避免给社交事件附加不必要的触发限制。
- 旧版明确记录为自动生成的位置前提，会在编辑器同步事件设置时移除；作者手动添加的位置条件保留。
- “非假期”选项统一生成 `2,8,-1`，并兼容旧版条件目录缓存，无需清理缓存。

本次为轻量更新。已有客户端可在“工坊设置 → 版本与反馈”中检查更新。

定向回归及完整浏览器编辑器的选择、应用、保存、重开流程已通过。未操作玩家实际模组，未做游戏实机验收。所核对的原版源码快照中，`2,8,0` 与 `2,8,-1` 均表示非假期；本次统一选项输出，并不将所有事件无法触发的问题归因于 `0`。
