# 拾光工坊 1.4.9.4

- 修复原版音乐播放时媒体请求占住设置目录锁、导致编辑操作与保存长时间等待的问题。
- 音频缓存无法读取时返回完整错误响应；切换歌曲取消旧连接不再被记录为内部错误。
- 播放列表新增「白日」（King Gnu）与「水星」（Lovely Summer Chan），依次置顶第一、第二；保留原来的音乐、个人曲库、音量与循环偏好。
- 优化大型模组新建空事件、对话顺序与条件目录读取；避免为目录生成逐句创建代理。
- 送礼、物品、插件与独立 JSON 保存不再额外载入整张对话表。已有事件标题保存仅提交事件表，保留正文、分支、未知字段与备份。
- 移除本地对话文件预判行数及体积限制；实际读取或数据格式错误仍如实提示。

原版音频慢读与错误响应回归通过，两首新曲的 Windows 原生播放已验证。原版曲目的 Windows 原生完整播放本轮未完成。50 万句隔离测试中送礼、物品保存保持原对话字节完整；首次载入与剧情正文、分支保存仍可能较慢，未取得反馈者原模组，不宣称原崩溃触发条件全部覆盖。

这是编辑器轻量更新，可在已有客户端的“工坊设置 → 版本与反馈”中检查更新并保存重启。Release 附件提供相同的轻量更新包及 SHA-256 校验文件。标签使用 `v1.4.10-beta.4` 以兼容旧更新器的版本排序，界面显示 1.4.9.4。
