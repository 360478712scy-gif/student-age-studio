# 拾光工坊 1.3.11.2

本次针对素材缓存读取和长时间使用时的响应问题进行修复：

- 已缓存的图片预览只检查相关素材配置，减少重复扫描整套模组及对其他编辑操作的阻塞。
- 保存后自动回收失效的素材目录缓存，避免旧目录持续积累。
- 合并频繁触发的后台素材扫描，减少重复工作。
- 关闭素材选择窗口后释放图片和列表，取消旧读取请求与重试计时器；保留未保存草稿、撤销记录和磁盘图片缓存。
- 修正 Windows 素材文件夹新增图片后偶尔未被及时识别的问题。

使用界面和保存方式保持不变，保存与导入仍保留外部修改冲突保护。

已通过 Mac、Windows 后端回归，以及 Windows 原生窗口连续 25 轮背景与合成表情图片切换。尚未完整复现反馈用户的两三分钟等待，实际长时间使用效果仍需反馈。

界面版本为 1.3.11.2；更新协议使用旧客户端可识别的 1.3.12-beta.2，可从 1.3.11.1 正常升级。本次为轻量代码更新。
