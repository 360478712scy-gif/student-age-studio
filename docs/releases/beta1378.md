# 1.3.7.8

新增可选的毛玻璃界面：工坊设置 → 外观与偏好 → 玻璃质感 → 毛玻璃。支持原有晴昼、暮色、月夜三种配色，以柔和色层、细边缘与层叠阴影呈现质感，无需实时液态玻璃渲染。

配色与玻璃质感分别保存，切换立即生效，下次启动保留。已有用户继续使用原来的设置。毛玻璃启用时停止液态画布重绘，直接以毛玻璃启动时不创建液态渲染器。仍可随时切回液态玻璃。

保留编辑操作、草稿及游戏预览布局。三种配色、设置持久化、模式往返、停止重绘和 Mac 原生窗口中的中文草稿、保存重开已做隔离检查；本轮未进行 Windows 原生窗口和真实游戏验收。

本次为轻量在线更新，保存草稿后按原方式重启生效。
