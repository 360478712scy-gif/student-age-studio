# 拾光工坊 1.4.14 · 草稿保存与分支修复

- 移除未完成配置阻止保存的校验：未命名事件、物品、书籍，以及未填完的人物、动态、短信、目标、效果和音频设置可以保存草稿，问题以提醒显示。
- 未完成的送礼、社交和事件外对话绑定保留为草稿；已有有效游戏配置继续保留，补齐后可以正常生成。
- 修复条件目录中「对话到达」「本回合对话」只增加计数、不显示编辑内容的问题；对话引用按页显示，避免载入全部正文。
- 修复在原版编辑器删改分支后，编辑器残留无法删除的分支；清理失效分支记录时保留实际对话正文与连接。
- 修复放弃修改退出时的 `reading 'slice'` 错误，并正确恢复已保存的固定编号。

这是已有客户端的轻量更新，可在工坊设置 → 版本与反馈中检查更新。新用户可先安装 [完整客户端](https://github.com/360478712scy-gif/student-age-studio/releases/tag/v1.4.10-beta.5)。

已验证完整编辑器的保存、重开、分支修复和放弃退出流程；浏览器验证使用隔离模组，本轮未进行 Windows 原生窗口或游戏内验收。
