# 1.3.5 hotfix

修复人物换装后的可视化与游戏读取不一致问题。

- 人物退场再登场、切换场景后继续保留服装状态，表情按当前服装读取。
- 舞台与右侧人物面板共用表情图片选择；缺少对应学段的图片时遵循游戏备用规则并明确提示。
- 保留原始换装及表情指令，单纯打开预览不会改写模组。

验证：35 组场景回归，江望舒模组隔离副本的校服退场再登场、舞台与侧栏图片一致；预览前后 91 个 JSON 文件未变。Windows 原生界面与游戏内实机表现尚未验收。

此补丁沿用轻量在线更新。为兼容已安装客户端的版本比较，内部版本号为 `1.3.5-beta.1`，高于此前 `beta-1.3.5`，无需重下完整客户端。

保留若心知（ruoxingzhi，PR #1）的性能优化及署名，感谢贡献。
