# 拾光工坊 1.4.12 · 轻量更新

- 插件编辑模式的剧情“屏幕效果”新增 UP 视频播放、停止与移除。视频素材库只显示模组和自定义素材；导入自动转为 H.264＋AAC MP4，无音轨的视频保持无声。
- 视频可设置音量、循环、允许跳过、人物显示在视频上方及完整显示／裁剪铺满／拉伸。动态背景可继续对话；玩家需安装并启用支持视频效果的新版 UP 非官方补丁。
- 新导入的 BGM／音效自动生成 AAC 试听文件，并保留游戏用的真正 WAV 副本，兼容原版和 UP 音频加载。按实际编码识别文件，支持音频扩展名与内容不一致的情况。
- 左下角播放器记住手动播放／暂停和音量，关闭再打开沿用。剧情预览或试听临时暂停不会改变用户的播放选择。
- 修复对话效果字段为 null 时保存报错；保留未修改的原始字段及作者手写效果。
- 素材库转码期间其他编辑操作可继续响应；重复导入保留编号，保护无关同名文件、未知字段与未保存剧情。
- 视频文件夹选择兼容现有 Mac 客户端；更新后可以继续浏览文件夹，无需重装。

可在工坊设置 → 版本与反馈中检查更新。本版为已有客户端的轻量更新。

更新入口空白的旧版本用户，可先使用 [1.4.11 的更新入口恢复工具](https://github.com/360478712scy-gif/student-age-studio/releases/tag/v1.4.11)，恢复后检查更新。新用户可先安装 [1.4.9.5 完整客户端](https://github.com/360478712scy-gif/student-age-studio/releases/tag/v1.4.10-beta.5)。

真实音视频转码、导入／保存／冲突与并发回归，以及 Windows 原生 WebView2 的实际播放、保存和播放器关闭重开验证通过。UP 视频字段按插件源码核对；本轮未进行游戏内视频播放验收。
