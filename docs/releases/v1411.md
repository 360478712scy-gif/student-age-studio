# 拾光工坊 1.4.11 · 轻量更新

- 修复工坊设置“版本与反馈”只剩空边框、检查与重启更新按钮消失的问题。beta.3 引入的初始化顺序错误已修正，关闭重开或切换分类后更新面板仍可使用。
- 修复编辑器添加 BGM＋音效后，游戏里音效缺失或打断背景音乐的问题。保存会生成 UP 支持的音频配置；原版及自定义音效均可同时播放。
- 未开启插件编辑模式时，组合音频会明确提醒玩家需要安装并启用 UP 非官方补丁。已有组合音频请重新应用音频设置并保存模组。
- 保留范围 BGM、0 延续、多音效及独立音量；重复保存、删除或改号不会叠加指令，也不会清理作者手写的音频引用。
- 新建物品未填写名称或图片时，可以保存草稿并返回工坊主页，重开继续编辑。
- 音频快照验证使用文件指纹缓存，正文保存不再每次逐句解析整个音乐范围；外部修改仍能检测。

本版为已有客户端的轻量更新，可在工坊设置 → 版本与反馈中检查更新。

beta.3 等版本更新面板空白的用户：先关闭编辑器，下载并解压本页的 `update-entry-repair.zip`，双击「恢复更新入口.cmd」，再打开编辑器检查更新。工具先备份当前前端文件，再恢复更新入口；已经修复的文件无需重复修改。

新用户可先安装 [1.4.9.5 完整客户端](https://github.com/360478712scy-gif/student-age-studio/releases/tag/v1.4.10-beta.5)。如果更新入口空白，按上一段修复后更新到本版。

更新入口的完整设置页面、轮询回归与 Windows 原生 WebView2 关闭重开/切换分类/真实检查接口均已通过，并加入发布 CI。音频与物品修复通过 67 项相关回归、Windows 原生 WebView2 实际编辑与写盘验收，以及隔离 Unity 中 UP 1.0.23 的同时播放、切句清理和音乐切换验证。隔离游戏使用现有资产缓存，未覆盖反馈者原模组或自然周目。

版本标签和编辑器显示均为 `1.4.11`。1.4.9.7 已更新轻量通道，未单独创建 GitHub Release。
