# 1.3.9.1

本次仅更新三项：

1. 对话文本导入与导出支持选项和分支。“选项 名称”“选项：名称”“选项:名称”均可识别；连续选项属于同一前置对话。“分支”可省略编号，或写成“分支1”；独立一行“。”结束对话夹并回到正文。沿用现有对话夹、保存和一次撤销机制；文本不包含条件配置、动作和素材。
2. 修复后台立绘尺寸刷新导致拖动途中大小跳变的问题。拖动期间固定立绘尺寸，只改变位置，松手后按当前场景刷新。
3. 工坊设置 → 数据与维护 → 模组备份支持更改备份文件夹，立即生效并在重启后沿用。旧备份保留在原处，新备份写入新位置。

作者 Codex。已完成隔离文本结构与保存回读、事件外对话、撤销重做、立绘连续拖动和尺寸刷新对照测试，以及备份位置持久化与错误路径保护。未完成真实用户模组和 Windows 原生拖动验收。本次为轻量在线更新。
