# 拾光工坊 1.3.10-beta.3

轻量在线更新（约 2.4 MB），不用重新下载完整客户端。更新不会替换模组、素材缓存或偏好设置。

## 本次修复

- **换场景后人物再登场时，“初始站位”改不到地方**：在某一句换背景、或让人物退场后再登场之后，点“初始站位 · 左／中／右”会出现预览里人物不动、面板按钮却变了；更麻烦的是改动被写进了上一幕那句已经失效的登场指令，回到上一幕会发现那个人物被挪了位。现在按“画面上这条人物记录是哪一句建立的”定位，只改真正决定当前画面的那句；同一句有多位自动登场人物时会一起写明，不会因为调整一个人让同伴消失；“黑屏保留”（bg=-2）仍沿用原登场句；服装等动作带回的人物只补写登场指令，原指令与位移参数保留。

## 一并送达

以下改动已经合入但没随版本号发布，本版本首次送达客户端：

- 原版对话按需载入：原版资源编辑模式和“覆盖原版事件”不再是空事件，也不再误报“与原版冲突”；只载入打开过的事件，不会把整部游戏的对话一次读进来。
- 剧情事件标题旁的排序按钮（按事件 ID／按名称，记住选择）、“原版事件”分类筛选、右下角“合并模组”工具（人物与其他重复记录冲突可选保留哪个）。
- 通知类事件卡片标明“仅通知文本，无对话”并显示通知内容。
- 修复一个事件里混进另一个事件对话的问题：对话归属以实际连接为准，记录里的旧归属只用于保留尚未接上的孤立段落。
