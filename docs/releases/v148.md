# 拾光工坊 1.4.8

**新主题「夜幕 · 剧场」**（工坊设置 → 外观与偏好 → 界面主题）
- 整个编辑器做成一座剧场：
  - 顶栏是红丝绒帷幔，挂着跑马灯招牌，两侧垂着幕布，底部是一排脚灯。
  - 工坊主页的功能做成一张张入场券，剧情事件做成海报。
  - 对话列表像一本剧本，当前句用荧光笔标出；舞台有镀金台口和帷幕。
- 动画：
  - 编辑器启动、回到工坊主页时，大幕会拉开；进入对话编辑时，舞台帷幕会拉开。
  - 鼠标移到入场券上，票会跟着倾斜；保存时脚灯会亮起。
  - 系统开启「减少动态效果」时，这些动画会自动关闭。
- 这个主题取代了原来的「纸本 · 工作室」，之前选纸本主题的用户会自动换成它。其他主题不受影响。

**结局段落修复**
- 修复编辑器里新建的结局段落在游戏里不出现的问题。原因是游戏只会播放以下几种段落：
  - 某个阶段的第一段；
  - 编号为上一段 +1 的段落；
  - 结局选项、相亲名单、职业结果直接跳到的段落。
- 新建段落的类型默认改为 1，和游戏自带的结局编辑器一致。
- 「阶段」「类型」改成带说明的下拉选择，列出了游戏的阶段顺序。
- 新增「接续下一段」：选中一段后点它，新段落的编号就是这段结局故事最后一段 +1，游戏会接着播放。
- 预览新增「在游戏中」一栏：
  - 说明这一段会在什么时候播放；
  - 不会出现时说明原因，并告诉你怎么改；
  - 类型设置不对时，可以一键「按游戏规则修正」。
- AI 通过 MCP 检查模组（check_mod）时，也会报告这些问题。

本次为编辑器轻量更新，不改动模组文件格式。
