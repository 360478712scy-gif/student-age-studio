# 拾光工坊 1.3.11.1

本次更新加强删除和保存保护，改善素材导入与少量操作体验。

- 删除事件时，保留其他事件共用的对白和选项；原有撤销、重做继续可用。
- 完整对话表意外缺行时拒绝保存，防止分页或截断造成数据丢失；正常分段保存和主动删除不受影响。
- 保存失败优先从磁盘快照恢复；部分恢复失败会保留快照并明确提示。开启自动清理时最多保留 20 份已完成的保存快照。
- 原版对白数据库空闲、切换游戏或关闭时释放句柄，减少文件占用。损坏的原版编辑记录可带提示打开，保存仍严格检查。
- 限制素材哈希队列与校验缓存，补齐保留编号处理。
- 支持 BMP、TGA 图片导入并转换为 PNG；目标图片保存前即可预览。
- 首步引导可跳过等待；保存审查默认返回修改；社交删除显示影响数量；目标错误字段自动聚焦；预览缺图保留备用显示并允许重试。
- 修正旧场景状态的登场定位，保留当前版本的直接来源定位及分段保存路径。

感谢若心知（ruoxingzhi）提交 PR #3 的原始实现和测试。Codex 完成融合审查、补充修复及验收，原作者提交历史保留。

验收覆盖完整后端测试、浏览器删除/撤销/保存、三主题 UI、TGA 预览、Mac 原生站位编辑与保存、真实立绘加载及拖动/切句/切学段缩放稳定性、约 37.6 MB 对话表连续保存及旧模组隔离副本的数据保留。性能数值仅代表本机隔离测试，不代表全部硬件；未进行真实游戏完整游玩验收。

版本说明：界面显示 1.3.11.1；更新协议沿用旧客户端可识别的 1.3.12-beta.1，保证 1.3.11 用户正常检测与升级。这是正式补丁更新。Windows 启动器的 Job 兼容修正已入源码，需后续完整客户端打包才能送达，不包含在轻量代码包内。
