# 拾光工坊 1.5.6 · 本句条件分支

剧情条件分支现在使用与原版编辑器一致的本句判定，不再为了添加分支生成空白连接对白。

- 在指定对白上添加条件，显示该句后按判定结果进入成功或失败去向。
- 打开、取消或重复编辑分支不会额外生成对白；原版剧情与模组剧情均使用同一格式。
- 保留已有旧版多分支连接与内容，以及原版男女主角各自的去向，不自动改写已有剧情。
- 失败去向留空时沿用成功去向；成功去向为空时结束对话。界面已明确提示。
- 已验证条件编辑、去向选择、保存重开、原版覆盖记录以及旧版分支和场景预览回归。

本次为轻量更新。在“工坊设置 → 版本与反馈”检查更新并重启即可，无需重新安装完整客户端。
