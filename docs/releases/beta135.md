# beta-1.3.5

修复内置编辑器创建的空事件框架无法直接进入对话编辑的问题。

- 尚未创建首句的事件可以直接打开，添加对话或空白对话。
- 预留的入口编号空闲时直接沿用并固定，事件编号、条件和其他配置保留。
- 如果入口已被原版或其他模组占用，新增本地对话并保留原引用，避免覆盖已有内容。
- 多个入口继续保留，自动编号避开尚未创建的入口。
