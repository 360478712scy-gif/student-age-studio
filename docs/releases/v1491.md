# 拾光工坊 1.4.9.1

- 修复后台缓存素材时编辑器卡住、操作不了的问题。
  - 原因：缓存期间，读取编号目录和声音列表会占用编辑器服务好几秒，打开对话、保存等操作只能排队等待。
  - 现在这两项不再阻塞其他操作，本身也更快了（声音列表约快 6 倍，编号目录约快 2 倍）。首次缓存或重建缓存时，也可以正常编辑。
- 事件设置恢复「事件效果」栏。
  - 漫展、生日派对、上海世博会事件：可以直接编辑事件效果，游戏打开这些页面时执行。
  - 普通对话事件：游戏里不会执行事件效果。这一栏会说明应该把效果加在对话的「本句效果」里，游戏显示这句对话时执行。以前存过的事件效果会列出来，可以一键清除。

本次为编辑器轻量更新，不改动模组文件格式。
