拾光工坊 Windows beta 1.0.0

完整解压文件夹，双击“拾光工坊.exe”。请保留同目录的 runtime 文件夹。
支持 Windows 10 / 11 64 位；已在 Parallels 的 Windows 11 ARM 中验证。
内置运行组件，不需要安装 Python。界面使用 Microsoft Edge WebView2；缺少时按启动提示安装微软 WebView2 Evergreen Runtime。

打开后自动查找本机的《学生时代》。右上角“位置设置”可切换安装位置、扫描磁盘、选择本地模组文件夹。
本地模组通常位于 %USERPROFILE%\AppData\LocalLow\PakyiGame\StudentAge\Mods。
订阅模组支持查看和预览，点击“创建副本”后编辑。人物、场景、CG、BGM、音效目录均支持原版、全部模组和自添加素材。

顶部“显示 ID”开关默认开启，在事件、对话、物品、动态和素材名称前显示 [ID]。点击可隐藏，重启后仍保留；隐藏后也能按编号搜索。编号不写进名称或游戏预览。

人物页上方包括人物资料、成长与喜好、表情与服装。右侧始终预览当前人物，表情与服装在同一行选择。
表情与服装里可加入角色服装并指定穿着地点；未指定的地点使用默认服装。点击右侧立绘也会选择图片和地点。
每套服装的第一张立绘为默认表情，后续图片作为同套服装的表情差分；每张图片的表情名称可自定义，已取消独立添加空表情的入口。
别名与电话号码在同一行，支持中英文逗号分隔多个别名。
游戏内按地点自动换装需另外安装 StudentAgeStudio-GameHelper-Windows-2.29.0；编辑器预览无需此组件。

工坊主页包括剧情事件、人物、物品、企鹅动态、人物空间等全部编辑入口。
剧情先选择事件，再编辑对话；直接在舞台对话框输入文字，拖动人物设置位移。
右键人物调整高光、翻转和退场；动作窗口可设置延迟、组合动作并播放。
左侧支持拖动排序、对话副本、选项与条件分支。完整预览点击舞台继续，出现选项或分支时点击选择。
导入与导出共用“人物名 空格 对话内容”的逐行文本格式。
企鹅动态支持评论、跟评、条件和效果；自建人物可以设置企鹅空间头像、签名、音乐、黄钻、名片和留言。
原版人物表情直接从已安装游戏读取，不需要启动游戏；首次生成在后台进行，生成后复用缓存。

所有编辑板块都有保存、撤销和重做；Ctrl+S 保存。顶部“自动保存”默认关闭并记住选择。关闭时，离开未保存内容会询问保存、不保存或取消；开启时自动保存。保存失败时保留窗口和草稿。
打开本地模组开始编辑会自动备份完整模组；左上角“手动备份”先保存当前修改，再备份。
默认每个模组保留最近五份备份，可在“位置设置 → 模组备份”关闭自动清理。
备份目录默认是 %LOCALAPPDATA%\StudentAgeStudio\ModBackups，备份不会混进模组列表。
